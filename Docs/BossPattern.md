# 보스 패턴 설계 문서

## 보스 개요

최종 스테이지의 보스로, 총 2개의 페이즈와 4개의 패턴으로 구성된다.

페이즈 1에서는 보스 본체가 직접 공격하며, 페이즈 2에서는 소환 및 추적형 공격을 사용한다.

일부 패턴 오브젝트는 부유하는 형태의 이동 로직을 사용한다.

- 화염 브레스 : 보스가 직접 발사하며 지형과 충돌하지 않는다.
- 소환 슬라임 : 전장 내 특정 위치에 생성되며 지형과 충돌한다.

---

# 페이즈 1

## 패턴 1 : 돌진 (Charge)

### 설명

보스가 플레이어를 향해 빠르게 돌진하는 패턴이다.

### 진행 과정

1. 보스가 돌진 준비 위치로 이동한다.
2. 플레이어 방향을 확인한다.
3. 빠른 속도로 직선 돌진한다.
4. 목표 지점에 도달하면 공격을 종료한다.
5. 다음 패턴으로 전환된다.

### 공격 특징

- 높은 이동 속도를 가진다.
- 이동 경로에 있는 플레이어에게 피해를 준다.
- 보스의 직접적인 근접 공격 패턴이다.

---

## 패턴 2 : 화염 브레스 (Fire Breath)

### 설명

보스가 여러 방향으로 화염 브레스를 발사하는 원거리 공격 패턴이다.

### 진행 과정

1. 보스가 중앙 위치로 이동한다.
2. 여러 방향으로 화염 브레스를 발사한다.
3. 일정 시간이 지난 후 동일한 공격을 반복한다.
4. 공격 종료 후 페이즈 2로 전환된다.

### 공격 특징

- 보스 위치를 기준으로 발사된다.
- 여러 방향으로 화염탄이 생성된다.
- 화염탄은 부유하는 형태로 이동한다.
- 지형과 충돌하지 않고 이동한다.
- 전장의 넓은 범위를 공격한다.

---

# 페이즈 2

페이즈 1 종료 후 보스의 외형이 변경되며 페이즈 2로 진입한다.

---

## 패턴 3 : 슬라임 소환 (Summon Slime)

### 설명

보스가 전장 내 여러 위치에 슬라임을 소환하는 패턴이다.

### 진행 과정

1. 보스가 소환 패턴을 시작한다.
2. 지정된 위치에 슬라임을 생성한다.
3. 일정 시간이 지난 후 추가 슬라임을 생성한다.
4. 소환된 슬라임과 함께 전투가 진행된다.
5. 패턴 종료 후 다음 공격으로 전환된다.

### 공격 특징

- 보스가 직접 발사하지 않는다.
- 전장 내 지정된 위치에서 생성된다.
- 슬라임은 부유하는 형태로 이동한다.
- 지형과 충돌하면 튕기며 이동한다.
- 플레이어는 보스와 슬라임을 동시에 피해야 한다.

---

## 패턴 4 : 유도 미사일 (Homing Missile)

### 설명

보스가 플레이어를 추적하는 유도 미사일을 생성하는 패턴이다.

### 진행 과정

1. 보스가 공격 준비 상태에 진입한다.
2. 유도 미사일을 생성한다.
3. 일정 시간이 지난 후 추가 미사일을 생성한다.
4. 생성된 미사일이 플레이어를 추적한다.
5. 패턴 종료 시 남아있는 미사일을 제거한다.

### 공격 특징

- 플레이어를 지속적으로 추적한다.
- 여러 개의 미사일이 순차적으로 생성된다.
- 플레이어의 이동 경로를 제한한다.

3. 슬라임 소환

# 보스 클리어

모든 패턴을 완료하면 보스가 처치된다.

보스 처치 시 플레이어의 클리어 시간이 기록되며, 해당 기록은 랭킹 시스템에 저장된다.

이후 메인 메뉴로 이동하여 랭킹을 확인할 수 있다.
